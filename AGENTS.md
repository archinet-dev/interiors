# AGENTS.md

Guidance for AI coding agents working in this repository lives in **`CLAUDE.md`** — read it in
full before making changes. It covers the product, the hard constraints (framework-free vanilla
JS, no build step, no secrets in the client, Bun backend), the required state/render contract,
how to run and verify the app, and the vertical-slice methodology.

The product spec and ultimate source of truth is **`PROMPT.md`**; the current capability ledger
is in **`README.md`**; pass reports, verification, design references, and the decision log are
under **`docs/`**.

This file is intentionally a pointer so agent guidance has a single home and cannot drift.
